#### Experiments

Use the controls above. The first plot shows the probability of each of the 64 bitstrings at the chosen input:
the black curve for the target circuit, the coloured curve for the fitted circuit,
and dots for the frequencies in the new samples.
The gap between the two curves is the model error. The scatter of the dots around the coloured curve is sampling error.
In the second plot, each row is one new six-bit sample.

Start at the default settings: 12,000 training pairs, 2,048 generated samples, qubit 1, and the input All zero.
Each task below changes one control. Write down your prediction before you open the expected result.
