For the chapter's device, at which query frequencies $b$ is $\lambda(ib)=0$? Explain it with the two Gaussians.

Where $\cos(1.8b)=0$: $b=\pi/3.6=0.87$, $3\pi/3.6=2.62$, and so on. There the distance 1.8 between the centres is an odd number of half periods of the wave. The two Gaussians see opposite values of the wave, and their contributions to the mean cancel.
