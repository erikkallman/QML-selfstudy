Why does a memory give no gain when the query is known in advance?

A known query needs one direction of phase space, for example $X$ for $\beta=ib$. One mode squeezed in $X$ and measured by homodyne detection then gives noise variance $e^{-2r}/4$, half the $e^{-2r}/2$ of the memory scheme. The memory pays for covering every direction at once, and a known query does not need that.
