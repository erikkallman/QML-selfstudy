Why must the memory bypass the device?

The real part of the sample is $X_\text{p}-X_\text{m}$. It contains $\operatorname{Re}\alpha$ only because the displacement acts on the probe alone. If the device displaced both modes by $\alpha$, $\operatorname{Re}\alpha$ would cancel in $X_\text{p}-X_\text{m}$, and the sample would carry no information about the device.
